# IOT-Based-Health-Monitoring-System
Health Monitoring Device

This project measures Heart Rate (BPM), SpO2, Temperature, and Humidity using various sensors. The data is shown on LCD and OLED displays and uploaded to Blynk and ThingSpeak for remote monitoring.

Features

BPM and SpO2 monitoring

Temperature & humidity measurement

LCD + OLED display output

Data upload to Blynk and ThingSpeak

Hardware Used

Microcontroller (ESP32 / Arduino)

MAX30100 / Pulse Sensor

DHT11

LCD (16x2 I2C)

OLED Display
